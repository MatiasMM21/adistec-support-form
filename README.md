# Adistec Support Form

Formulario de soporte técnico de Adistec integrado con Freshservice.

## 🌐 URL del formulario

https://matiasmm21.github.io/adistec-support-form/

## 📋 Servicios incluidos

- Progress Support
- AIS (Intel & SuperMicro)
- AEC (Adistec Enterprise Cloud)
- AWLC (VMware & Veeam)
- Labs
- Education

## 🔧 Uso en Freshservice

Pega este código en la página de "Nuevo Ticket" de Freshservice:

```html
<style>
  .iframe-wrapper {
    width: 100%;
    min-height: 900px;
  }
  iframe {
    width: 100%;
    height: 900px;
    border: none;
  }
</style>

<div class="iframe-wrapper">
  <iframe src="https://matiasmm21.github.io/adistec-support-form/" 
          scrolling="yes">
  </iframe>
</div>
```
